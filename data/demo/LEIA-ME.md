# Dados de demonstração

Esta pasta guardará dados **fictícios** usados apenas para testar telas.

Regras obrigatórias (decisão do projeto):

1. Todo arquivo aqui deve ter o campo `"demonstracao": true`.
2. Na tela, todo dado de demonstração aparece com o selo **Demonstração**
   (classe CSS `selo-demo`).
3. Nunca usar números que pareçam estatísticas reais do ENEM, nem fontes,
   probabilidades ou resultados de provas inventados.
4. Dados de demonstração nunca são enviados para o Supabase.

Na etapa 1 esta pasta está vazia de propósito.
